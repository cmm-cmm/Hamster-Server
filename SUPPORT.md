# Support

Use [GitHub Discussions](https://github.com/cmm-cmm/Hamster-Server/discussions) for
setup questions and general usage help. Search existing discussions and issues first.

Use the bug report template for reproducible defects. Include the Hamster Server,
.NET, Windows, Apache, and PHP versions involved, along with sanitized logs. Never
post secrets, private keys, certificates, or machine-specific credentials.

Report security vulnerabilities privately as described in [SECURITY.md](SECURITY.md).
