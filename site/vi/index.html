Apache và PHP trên Windows, không cần sửa file cấu hình.

Hamster Server là web server cục bộ miễn phí, chạy di động trên Windows. Ứng dụng đóng gói sẵn Apache 2.4 và PHP 8.2–8.5 cùng một bảng điều khiển tự viết mọi file cấu hình cho bạn, tự giữ PHP ở bản vá mới nhất, và chỉ đích danh chương trình đang chặn khi một cổng bị chiếm.

Cổng

“Cổng đã bị chiếm” — bởi ai?

Cửa sổ Ports liệt kê mọi cổng TCP đang lắng nghe trên máy, kèm địa chỉ, chương trình và PID. Nó cũng cho biết từng cổng của Apache có trống hay không, trước khi bạn bấm Start.

Virtual host

Mỗi dự án một tên riêng.

Thêm site, chọn thư mục và preset framework, Hamster Server sẽ tự khởi động lại Apache. Bạn có thể bật hoặc tắt từng site, mở trong trình duyệt hoặc mở thư mục của nó.

Tên kết thúc bằng .localhost dùng được ngay. Với mọi tên khác, Hamster Server kiểm tra file hosts của Windows và hiện đúng dòng cần thêm:

Chỉ máy này

Apache lắng nghe trên 127.0.0.1. Mở ra mạng nội bộ là một công tắc riêng, phải bật có chủ ý.

Chỉ php.net, qua HTTPS, để kiểm tra và tải PHP. Không telemetry. Tắt cập nhật thì không còn gì kết nối Internet.

Hỏi đáp

Câu hỏi thường gặp.

Hamster Server là gì?

Hamster Server là web server cục bộ miễn phí, mã nguồn mở cho Windows. Nó đóng gói sẵn Apache HTTP Server và PHP 8.2 đến 8.5 cùng một bảng điều khiển tự tạo toàn bộ cấu hình, nên dự án PHP chạy ngay tại http://localhost/ hoặc dưới tên như shop.test mà không phải sửa httpd.conf hay php.ini.

Hamster Server có miễn phí không?

Có. Hamster Server miễn phí và mã nguồn được phát hành theo giấy phép MIT. Các bản Apache và PHP đi kèm giữ giấy phép mã nguồn mở riêng của chúng.

Hamster Server đi kèm những phiên bản PHP nào?

Phiên bản 1.4.1 đi kèm PHP 8.2.35, 8.3.36, 8.4.27 và 8.5.12 (Non Thread Safe, x64, bản build lại -1 cho Windows), đã có bản vá cho lỗ hổng PHP2Shell CVE-2026-109618 và CVE-2026-109619. Có thể cài thêm bất kỳ bản Windows chính thức nào từ php.net trong PHP Version Manager, và nhánh đang dùng được tự đưa lên bản vá mới nhất trừ khi tắt cập nhật.

Hamster Server có tự cập nhật PHP không?

Có, theo mặc định. Ứng dụng kiểm tra php.net một phút sau khi khởi động và sáu giờ một lần, cài bản vá mới hơn của nhánh PHP đang dùng bên cạnh bản hiện tại, rồi chuyển sang khi không có request nào đang chạy. Có thể chọn chỉ thông báo, hoặc tắt hẳn. Ứng dụng không bao giờ tự chuyển sang nhánh PHP khác.

Extension như sqlsrv hay Xdebug có còn sau khi cập nhật PHP không?

Có. Các DLL extension bạn thêm vào thư mục ext của một runtime, cùng các DLL mà chúng cần, được chép sang bản vá mới của cùng nhánh PHP. File mà bản vá mới đã có sẵn không bao giờ bị ghi đè. Extension không được chép giữa hai nhánh (ví dụ 8.4 sang 8.5) vì chúng được build riêng cho từng nhánh.

Hamster Server có cần cài đặt hay quyền quản trị không?

Không. Đây là một thư mục di động: giải nén file zip vào nơi có quyền ghi rồi chạy HamsterServer.exe. Cần Windows 10 hoặc 11 (x64) và .NET 10 Desktop Runtime.

Hamster Server có kèm MySQL hay MariaDB không?

Không. Hamster Server đóng gói Apache và PHP. Các extension MySQL, PostgreSQL, SQLite và SQL Server của PHP có thể kết nối tới máy chủ cơ sở dữ liệu bạn chạy riêng; cửa sổ Ports cho biết máy chủ cơ sở dữ liệu nào đang lắng nghe.

Vì sao tên virtual host của tôi không mở được trong trình duyệt?

Windows phải biết tên đó trỏ về máy này. Tên kết thúc bằng .localhost dùng được ngay; mọi tên khác cần một dòng như 127.0.0.1 shop.test trong file hosts của Windows. Hamster Server kiểm tra file hosts và hiện đúng dòng cần thêm.

Hamster Server kết nối tới đâu trên Internet?

Chỉ windows.php.net và downloads.php.net qua HTTPS, để kiểm tra và tải các bản PHP; bản tải về chỉ được cài khi khớp checksum SHA-256. Đặt cập nhật thành Off thì ngay cả kết nối đó cũng không còn. Apache chỉ lắng nghe trên máy này, trừ khi bật truy cập mạng LAN.
